¿En qué consiste?
1. Desarrollar una plataforma que analiza reformas en profundidad para áreas prioritarias para
la región
2. Se analizarán 2 temáticas prioritarias
3. Para cada temática, se abordarán 3 casos en profundidad y análisis comparado entre ellos.
4. Cada caso contendrá:
• Descripción del caso: proceso histórico, social y legislativo asociado a cada reforma.
• Evaluaciones
• Indicadores
• Entrevistas
